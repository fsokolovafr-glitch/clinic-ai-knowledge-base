# Claude Context

This repository is the source-of-truth knowledge base for clinic and aesthetics content. It is expected to hold the core master overview, the source index, and a normalized asset library under `sources/`.

## Required structure

- `README.md`
- `MASTER_KNOWLEDGE_BASE.md`
- `CLAUDE_CONTEXT.md`
- `SOURCE_INDEX.json`
- `sources/`

## Source asset conventions

- Use stable naming with prefixes like `S01_`, `S02_`, etc.
- Keep vendor documents grouped under `sources/`.
- Maintain the index file in sync with files added or removed.
