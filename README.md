# Clinic AI — промежуточная база знаний

Версия 0.1.0 · 18 сентября 2026

Основной редактируемый файл: [MASTER_KNOWLEDGE_BASE.md](MASTER_KNOWLEDGE_BASE.md).

В нем собраны сведения из 7 уникальных PDF (260 PDF-страниц): M17, HydroPeptide, GenX Exosomes & Polynucleotides и каталог md:complex/md:peel. Включены 70 подробных карточек HydroPeptide, отдельный Men's Facial, обзор шести Power Facial Series, карточки md:complex, пилингов и домашнего ухода, реестр claims, расхождений и недостающих данных. Второй Training Guide проверен по SHA-256 и исключен как точный дубль.

## Файлы

- `MASTER_KNOWLEDGE_BASE.md` — единый справочник, включая реестр источников и правила работы с неопределенностью.
- `SOURCE_INDEX.json` — машинно-читаемый реестр исходных имен, путей, объемов и контрольных сумм.
- `CLAUDE_CONTEXT.md` — короткий текст задачи для работы с базой.
- `sources/` — исходные PDF и первоначальная постановка задачи; документы сохранены без изменения.

## Для Claude

Передайте `MASTER_KNOWLEDGE_BASE.md` как справочный файл. Текст из `CLAUDE_CONTEXT.md` можно использовать как вводное задание. Основные сведения находятся в master-файле; для спорных формулировок прикрепляйте соответствующий исходный PDF. Ссылки вида S03, PDF с. 53 сохраняются и без открытия локальных ссылок.

Русские разделы дают структуру и ограничения. В подробных карточках HydroPeptide применение и противопоказания сохранены на английском языке источника, чтобы не исказить дозировки и ограничения.

## Для GitHub

Распакуйте архив и перенесите его содержимое с сохранением папки `sources/`: относительные ссылки останутся рабочими. Master — обычный UTF-8 Markdown; редактируется как текст, изменения удобно сравнивать по версиям. Репозиторий в рамках этой задачи не создавался, файлы никуда не публиковались. Пакет рассчитан на внутреннюю работу с предоставленными материалами; публичное распространение оригинальных PDF не предполагается.

## Граница готовности

Это промежуточная база по источникам, не утвержденный протокол клиники. «Указано в инструкции» означает наличие формулировки в документе, а не независимую клиническую валидацию. Внешние исследования не проверялись. Недостающие противопоказания, INCI, параметры, пути введения и интервалы не додуманы.

Для клинического применения нужны действующие инструкции конкретных продуктов, недостающая страница Esthetics Guide, полные протоколы и перечень доступных клинике процедур. Все пробелы перечислены в разделе 8 master-файла.
