# Clinic AI Knowledge Base

This repository contains the curated knowledge assets used by the clinic AI assistant. It includes the repository-level instructions, the master knowledge base summary, and the source library for clinical and product documentation.

## Included files

- `CLAUDE_CONTEXT.md`
- `MASTER_KNOWLEDGE_BASE.md`
- `SOURCE_INDEX.json`
- `sources/`

## Source library

The source documents under `sources/` include brochures, technical dossiers, user manuals, product catalogues, and project briefs.
