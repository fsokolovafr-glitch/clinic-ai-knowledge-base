# Master Knowledge Base

This document defines the repository's baseline structure for clinic, product, training, and technical knowledge assets.

## Repository scope

- Product references
- Protocol and user guidance
- Training and certification documentation
- Brand catalog assets
- Internal brief and technical dossier content

## Asset sources

The bibliography is indexed in `SOURCE_INDEX.json` and the source files live under `sources/`.

## Governance

- Keep file names stable and machine-readable.
- Store source materials in `sources/`.
- Update `SOURCE_INDEX.json` when the asset set changes.
